============================================================
 YUN-YUN-LOVE  便携版  v1.0.0
 晕晕电波症候群 (Yunyun Syndrome) 自定义 4K 谱面商城辅助
 作者：是ShaShen吖
============================================================

【是什么】
  注入式覆盖层（DLL + DXGI/ImGui）。导入 4K 谱面包 .zip（Malody .mc / osu!mania .osu），
  以"商城大卡片"的形式浏览，点开曲目选难度后，直接进入游戏原生游玩界面游玩
  你导入的谱面（打击判定 / 连击 / 晕晕动画 / 结算全部走游戏原生逻辑）。
  非 4K 谱面（5K+ / taiko / catch / osu!std）导入时会被自动过滤。

【运行环境】
  - Windows 10 / 11  64 位
  - 必须已安装 Steam 正版《晕晕电波症候群》(Yunyun_Syndrome)
  - 不需要安装 VC++ 运行库（已静态链接 /MT），不依赖任何第三方 DLL

【怎么用】
  1. 双击  StartYunYunLove.bat
     （它会自动：启动游戏 -> 等游戏起来 -> 注入覆盖层）
     如果注入失败，右键该 bat「以管理员身份运行」。
  2. 也可以手动两步：
     a) 先启动游戏（Steam 库里运行，或 steam://rungameid/2914150）
     b) 游戏起来后，双击 Injector.exe
  3. 屏幕会浮出商城界面：
     顶部   搜索框 + [搜索] + [导入 Malody 谱面]
     中间   大卡片网格（一行 5 个，封面 + 曲名 + 艺术家/版本）
     底部   分页  < 1 2 3 ... N >
     左侧栏 谱面商城 / 游玩设置 / 商城设置 / 关于
  4. 点 [导入 Malody 谱面] -> 选一个 4K 谱面包 .zip -> 自动解包收录（自动过滤非 4K）。
      同一个 .zip 里的多张谱面（.mc / .osu）会各自成为一张难度卡。
  5. 点卡片进入曲目详情页（左上角 <- 返回）-> 选难度 -> [开始游玩]。
  6. 想删掉某个曲包：卡片右上角悬停出现垃圾桶角标（详情页也有「删除曲包」），
     确认后递归删除 <游戏目录>\YunYunLove\Store\<曲包id>。

【常用操作】
  INSERT        显示 / 隐藏界面
  END           卸载覆盖层（恢复正常游戏）
  拖动标题栏     移动窗口
  拖窗口边框     自由缩放窗口（右下角有三条斜线提示，松手后尺寸会记住）
  右上角 X       把窗口缩成一个可拖动的小球（点小球还原）
  游玩设置 -> 谱面同步微调   个别谱面作者同步不准时，±0.3 秒内手动对齐

【运行数据在哪】
  <游戏目录>\YunYunLove\Store\<曲包id>\   解包后的谱面 + entry.txt
  <游戏目录>\YunYunLove\config.json      设置
  %LOCALAPPDATA%\YunYunLove\log.txt      运行日志（出问题时看这个）

【卸载】
  游戏内按 END，或直接退出游戏；覆盖层是内存注入，不修改游戏任何文件。
  想彻底清理：删掉 <游戏目录>\YunYunLove\ 整个目录即可。
